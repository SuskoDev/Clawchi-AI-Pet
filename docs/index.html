// GET STARTED
3 STEPS TO A LIVING CRAB
Clone, deploy, connect. Takes about 5 minutes.
01

LOAD THE EXTENSION

Clone the repo, open chrome://extensions, enable Developer mode, and load the folder.

git clone https://github.com/SuskoDev/Clawchi-AI-Pet.git
02

DEPLOY YOUR RELAY

Create a free Cloudflare Worker. It takes 2 minutes and costs nothing.

cd cloudflare-worker && wrangler deploy
03

CONNECT YOUR AI

Paste the relay URL in settings, copy the Agent Prompt, and paste it into your AI tool.

COPY AGENT PROMPT → PASTE INTO AI
